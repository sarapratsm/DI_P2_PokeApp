PokeUI - WPF Pokédex
Una aplicación de escritorio moderna desarrollada en WPF (Windows Presentation Foundation) para visualizar información detallada de Pokémon. El proyecto utiliza una arquitectura limpia basada en UserControls reutilizables y conecta con una base de datos MySQL mediante Entity Framework Core

🛠️ Tecnologías y Herramientas
  Lenguaje: C# (.NET 6/8)
  Framework UI: WPF (XAML)
  ORM: Entity Framework Core (Pomelo MySQL Provider)
  Base de Datos: MySQL / MariaDB
  Librerías Adicionales:
  CommunityToolkit.Mvvm (o similar para generadores)
  DependencyPropertyGenerator (para simplificar la creación de controles)
